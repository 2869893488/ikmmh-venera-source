# ikmmh-venera-source
爱看漫（ikmmh.com）的 Venera 漫画源配置。
## 说明
脚本通过网站阅读页使用的接口获取正文图片地址，用于修复章节图片无法正常加载的问题。
本项目仅提供 Venera 漫画源配置文件，不包含任何漫画图片、账号信息、Cookie 或付费内容。
## 使用方法
1. 下载 `ikmmh.js`
2. 在 Venera 中导入本地漫画源
3. 搜索或打开爱看漫漫画进行阅读
## 支持情况
- 支持漫画信息与章节列表读取
- 支持正文图片读取
- 支持 `/api/comic/read/pics` 返回的 UUID 图片地址
- 保留常见图片路径规则兼容
## 注意
如果导入后没有变化，请先删除旧的同名漫画源，再重新导入本文件。
## 来源说明
本配置基于已有的 ikmmh Venera 漫画源修改而来，主要调整了章节图片获取逻辑，以兼容网站当前的移动阅读页接口。
